**The Project:**

**AI Implementation:**

* Built an automated pipeline to securely sync credit card statements directly from Gmail
* Designed an LLM-based transaction categorization engine achieving **95%+ accuracy**, significantly outperforming traditional rule-based systems

**Business Impact:**

* Reduces manual expense tracking to near zero
* Enables scalable personal finance insights without increasing data risk

**Key Insight:**
Replacing static rules with LLM reasoning transforms financial data processing from rigid classification into **adaptive intelligence**.
